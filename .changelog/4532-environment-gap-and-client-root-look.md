- **One workspace root per session, a worktree install restart, an adopted root's shim refused.** Environment-gap codes (TS2307 on a `node:` or bare specifier, TS2503 for `NodeJS`, TS2304 for `node`'s globals) are demoted to warnings with a label when the file resolves no `node_modules`; the `tool_call` config init registers one workspace per session — the nearest `.pi-lens.json` owner below the session root, or a linked worktree's own root — instead of `path.dirname(filePath)`, so 200 edited directories no longer evict the project root and its `lsp.disabledServers` denial, and an adopted root registers nothing, so its two-root cap and project-local-binary refusal keep applying; the out-of-band install look runs at the roots of the live primary clients with each client's spawn epoch, so a `node_modules` symlinked in after the server started restarts it; and `launchLSP` resolves a bare server command from PATH **in process** against the cwd the child is spawned with, so a relative `node_modules/.bin` entry (husky's generated `.husky/_/h` exports one for every git hook) can no longer make an adopted root's own shim exec unclassified, and no project-supplied `which` runs (refs #4532, closes #2657).
