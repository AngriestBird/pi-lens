- **`scripts/check-pr-body.mjs` now reads the `## Fold check` section AGENTS.md requires (#4711).** A PR opened with a raw `gh pr create` skipped the fold-check rule because the CI body lint never looked for the section, while the maintainer's local gate refused the same body; two fixer bodies on 2026-10-21 were refused only locally. The lint refuses a body with no section; a section holding neither a decision line (`#N` first, one of `folded` / `not folded` / `sequenced`, then the reason) nor `none: <reason>`; a decision spelling outside the three; a line naming a candidate without deciding it; `none:` beside a candidate line, whatever its reason's length; and a `folded` candidate the body never closes (a `Closes #N` in any fenced or indented code closes nothing). Both heading scans read the body through one CommonMark lexer, `marked` 18.0.11 (`scripts/lib/markdown-lexer.mjs`): a section is a top-level heading token, so a heading inside an HTML comment, a raw-HTML block, a list item or a block quote is refused, a setext, indented or closed ATX heading counts, a heading is named by its rendered text (an inline comment or emphasis around the name is fine), a comment a list item leaves open hides everything after it as GitHub renders it, and section text drops every raw-HTML block. The prose rules take their headings and section boundaries from the same lexer. The diff-keyed rows take their section boundaries from it too: a mutation or Controls table row under a setext or an indented ATX heading belongs to the section below that heading, so it cannot prove the section above it. `marked` is an exact devDependency loaded on first use, so the close-keyword jobs still run with no install; the PR body job installs that one package and checks it against the lockfile's sha512. The hand-written comment and code-span scanner in `scripts/lib/defect-shapes.mjs` and its copy in `scripts/check-prose.mjs` are deleted, so every gate that blanks markdown through that module reads it through the same lexer. The section's verdict parser stays the one `## Class sweep` uses, and only the admitted vocabulary differs; the candidate list stays the local script's to compute. The template, the flattened-body repair's heading list, the reviewer doc, and the commit/PR prose contract carry the section.
